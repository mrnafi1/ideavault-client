# IdeaVault 💡

A community-driven platform where people can share startup ideas, explore others’ concepts, and discuss feedback together. The platform facilitates creativity, collaboration, and validation of innovative ideas through active community participation.

🔗 **Live Site:** [https://ideavault-client-dusky.vercel.app](https://ideavault-client-dusky.vercel.app)

---

## ✨ Features

* **Submit Startup Ideas:** Share startup ideas with detailed information, including the problem statement, proposed solution, target audience, category, and estimated budget.
* **Trending Ideas Feed:** Explore trending ideas based on community activity and engagement.
* **Comment & Discuss:** Engage with ideas by posting comments, editing feedback, and managing your own discussions.
* **JWT-Secured Authentication:** Ensure data privacy with robust Firebase authentication and server-side JWT protection.
* **Sign in / Register:** Supports seamless user access with Google Sign-In and traditional Email/Password login.
* **Dark / Light Theme:** Enjoy a flexible UI with dark and light mode options that persist across your sessions.
* **Search & Filter:** Quickly find relevant concepts using a smart search bar (by title) and category-based filtering.

---

## 🛠️ Technologies Used

* **Frontend:** React (Vite), Tailwind CSS, React Router DOM
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** Firebase Auth, JWT
* **Deployment:** Vercel

## 📦 Getting Started Locally

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/mrnafi1/ideavault-client.git](https://github.com/mrnafi1/ideavault-client.git)
    cd ideavault-client
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Configure Environment Variables:**
    Create a `.env.local` file and add your Firebase configurations.

4.  **Run the development server:**
    ```bash
    npm run dev
    ```
